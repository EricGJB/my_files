## 六、Token 通信（TokCom / 语义 / AI 原生通信）

- **核心思想**：以 LLM 的 **Token 为"一等实体"**替代比特精确传输，将网络从"转发数据包的比特管道"变为"记忆、预测、主动助力的分布式神经处理基座"。与经典 SemCom（任务/模态紧耦合、难泛化）相比，TokCom 复用大模型共享 Token 嵌入空间，模态无关、可直接对接预训练模型。
- **架构要素**：多模态 Token 化（替代信源编码）→ 统一嵌入空间 → 多智能体协作调度 → Token 感知无线资源分配 → **生成式可靠性**（丢 token 用上下文 inpainting 恢复，替代 ARQ 重传）→ **分布式 KV-cache 仓库**（基站作持续上下文库，支持跨小区/边云无缝推理衔接）。
- **实证**：SLM–LLM draft-and-verify 案例接近 LLM-only 准确率，且每个正确答案生成 token 数 **减少 11.8%–16.8%**。
- **待解挑战**：幻觉传播（语义级错误比比特错误更难察觉）、KV-cache 爆炸（"内存墙"）、以及标准化缺失。
- **产业/标准呼应**：
  - **紫光展锐**：提出以 Token 为基本传输单元的**语义通信框架** + 联合 Token 编码与调制（JTCM），入选"6G 星辰·博士"。
  - **3GPP RAN2 #133** 已在讨论 **Tokenized traffic** 的 L2 协议适配（LLM 自回归 token 为非均匀突发、时延窗口严格）。
  - **OPPO 沈嘉（全球 6G 大会）**：面向 AI Agent 的语义传输、流量识别、小包优化与 **Token 通信机制**将是 6G 第二版标准核心。
  - **商业模式**：运营商从"卖流量"走向"卖 Token"（中国信通院：日均 Token 调用突破 180 万亿次，较 2024 年初激增 1000 倍）；华为数据：**网络时延每增 50 ms，任务 Token 消耗 +20%**；高通提出 **Token 即服务（TaaS）**新商业模式。
  - **西安交大/香港科大 HKUST 7G 路线**：Reasoning-Empowered Task-Oriented Communication（任务导向通信，智能体判断"值不值得发/发什么/发给谁"，意图解释 + 自动优化 + 主动前瞻），来自 npj Wireless Technology 2026。
